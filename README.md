**Course:** MCA  
**Subject:** Artificial Intelligence Lab  
**Course Code:** IC-709D  
**Institution:** International Institute of Professional Studies (IIPS), DAVV, Indore

## About This Repository

This repository contains practical implementations and laboratory assignments completed as part of the Artificial Intelligence Lab coursework.

The experiments cover fundamental AI problem-solving techniques, heuristic search algorithms, data preprocessing, knowledge representation, machine learning, deep learning, and advanced AI applications.

## Laboratory Sessions

| Lab   | Topics                                                          |
| ----- | --------------------------------------------------------------- |
| Lab 1 | AI Environment Setup, Production Systems, Water Jug Problem     |
| Lab 2 | BFS, DFS, Hill Climbing, Best First Search, A\*                 |
| Lab 3 | Data Preprocessing, EDA, NumPy, Pandas, Visualization           |
| Lab 4 | Knowledge Representation, Rule-Based Systems, Semantic Networks |
| Lab 5 | Decision Tree Classifier and Model Evaluation                   |
| Lab 6 | PyTorch Basics, Linear Regression, Neural Networks              |
| Lab 7 | Explainable AI, Adversarial AI, PCA/SVD, Mini Project           |

## Repository Structure

- `Lab1/` to `Lab7/`: Individual laboratory experiments.
- `datasets/`: Datasets used in experiments.
- `models/`: Trained machine learning and deep learning models.
- `docs/`: Reports, flowcharts, and architecture diagrams.
- `requirements.txt`: Python dependencies.

## Execution

Clone the repository:

```bash
git clone REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd IC-2K23-05-AI-Abdul-Rehman
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Install dependencies:

```bash
pip install -r requirements.txt
```
